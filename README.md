# AniSpace — персональный аниме-органайзер

**AniSpace** — это некоммерческий веб-инструмент для ведения личной библиотеки аниме. Позволяет отслеживать просмотренное, ставить оценки, создавать папки и витрины, а также искать аниме через базу Shikimori.

## Возможности

- 📚 Библиотека с категориями (Смотрю, Просмотрено, В планах и др.)
- ⭐ Личные оценки и рейтинг Shikimori
- 📁 Папки для организации коллекции
- 🏆 Витрины с топ-3 аниме и описаниями
- 🔍 Поиск аниме через Shikimori API
- 💾 Экспорт/импорт коллекции в JSON
- 🎨 Адаптивный дизайн в тёмных тонах

## Технологии

- HTML, CSS, JavaScript
- Shikimori API
- Локальное хранение данных (localStorage)
- Не требует сервера

- AniSpace не хранит изображения на своих серверах и использует прямые ссылки на кеш Shikimori.

AniSpace не собирает, не хранит и не обрабатывает персональные данные пользователей на сторонних серверах. Все данные (оценки, списки, настройки) сохраняются исключительно в локальном хранилище браузера пользователя (localStorage) и не передаются третьим лицам.
